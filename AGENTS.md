# Repository instructions

Use `snake_case` for full-stack application data end to end, including backend
DTO/JSON fields and their matching UI TypeScript API contracts. This repository-wide
rule overrides any older instruction or existing example that calls for `camelCase`
JSON fields.

For backend work, including backend tests, Python dependencies, migrations, and backend CI or configuration outside `tripper_api/`, read and follow [tripper_api/AGENTS.md](tripper_api/AGENTS.md).
